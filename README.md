# Humi Master Sale tool — BETA

Phần mềm quản lý cửa hàng xe điện trên Windows 64-bit. Dữ liệu bán hàng, khách hàng và công nợ lưu riêng trên máy của cửa hàng; Internet dùng để nhận bản cập nhật.

## Tải và cài đặt

[Tải bộ cài 2.0.4 BETA cho Windows](https://github.com/TuannAnhh24/humi-master-sale-releases/releases/download/v2.0.4-beta/HumiMasterSaleTool_Setup_x64.exe)

1. Mở file **HumiMasterSaleTool_Setup_x64.exe** vừa tải và làm theo hướng dẫn.
2. Mở **Humi Master Sale tool** từ Desktop hoặc Start Menu.
3. Thiết lập thông tin cửa hàng để bắt đầu sử dụng. Bộ cài không chứa dữ liệu demo.

Đây là phiên bản BETA đang tiếp tục hoàn thiện. [Xem các phiên bản và nội dung thay đổi](https://github.com/TuannAnhh24/humi-master-sale-releases/releases).

## Cập nhật khi đang sử dụng

Vào **Cài đặt → Thông tin phiên bản & cập nhật → Kiểm tra cập nhật**. Khi có bản mới, hoàn tất nội dung đang nhập rồi chọn **Cập nhật ngay**.

Phần mềm tự sao lưu, xác minh gói cập nhật, giữ nguyên dữ liệu và mở lại. Nếu bản mới không khởi động được, phần mềm phục hồi bản trước. Không cần gỡ ứng dụng hay tự nhập lại dữ liệu.

Các bản cũ chưa kết nối kênh cập nhật này cần chạy bộ cài mới một lần, sau khi lưu và đóng phần mềm. Không cần gỡ bản cũ.

## Các tệp trên kho này

- File **Setup** dành cho khách cài lần đầu.
- File EXE có tên phiên bản và `latest.json` phục vụ ứng dụng tự cập nhật.
- Kho phát hành không chứa dữ liệu cửa hàng hay mã nguồn ứng dụng.

Kênh BETA dùng tệp thông báo phiên bản có chữ ký tại `main/latest.json`, nên vẫn nhận được các bản GitHub Pre-release.
